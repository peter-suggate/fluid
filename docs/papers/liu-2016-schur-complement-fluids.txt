Boosting accuracy We use a high-order defect correction technique
[Trottenberg et al. 2001] to allow our approximate inverse of a first-
order discretization to be used as a CG preconditioner for a higher
order scheme. We structure our top-level PCG solver to implement
matrix-vector multiply operations in accordance with a second or-
der accurate discretization of the Laplace operator [Enright et al.
2003]. Upon invocation of the preconditioner, however, we per-
form the following steps: (i) We execute a few iterations of a Jacobi
smoother, using the 2nd order operator, (ii) we then compute the
residual, and multiply this with our first-order preconditioner, and
finally (iii) we again compute the residual r, write the error equa-
tion Ae = −r using the second order operator, which we solve
using the same number of Jacobi iterations. We finally add the cor-
