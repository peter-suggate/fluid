# Wet-cloth fluid constitutive audit

This maps the pinned Fei et al. (2018) equations and libWetCloth source to executable code. Passing a momentum test proves conservation, not agreement of constitutive coefficients or scene trajectories. Source files cited below are the pinned research checkout in `/tmp/fluid-wetcloth-research/libWetCloth`.

## Numerical differences that remain explicit

The pressure structural Schur complement is currently split across MAC faces; it does not include the full off-diagonal rank-one response of every structural control in a monolithic solve. Full-tensor drag uses conservative grid-coefficient quadrature lumped into colored structural blocks; each block is reciprocal and dissipative, but this is a split discretization rather than libWetCloth's global linear solve. The actual NB-FLIP grid constitutive regression passes with the new packing/mixture-volume assembly.

The manifold nonlinear drag now evaluates `C` at the released force-derived OUTER-`dt` Gauss velocity predictor (`LinearizedImplicitEuler.cpp:2668–2686`) inside saturation iteration. It retains the complete vector magnitude under rotation and shares the same Gauss coefficient among all triangle edges. The conservative implicit graph solve and paired positivity limiter differ from the released source fixed-point update with nodal clamping/global rescaling; source trajectory and refinement comparisons remain required. The source dimension-dependent minimum-D floor (`fluid_m_gauss/dt*1e-3`) is preserved through source-only `manifoldDragFloorReferenceVolume_m3=1e-6`: in SI the floor is `0.001*boundMass/(outerDt*referenceVolume)`. The explicit one-cubic-centimetre reference preserves the original CGS numerical regularizer without mislabeling it as a material law. Generic documents omit this floor.

The local capacity remap intentionally refuses unsupported stencils or disconnected donor reservoirs. Fine support must include the swept geometry, transport corridors, and actual cohesion sample points. No full-domain heating or remote surface rescaling is used to hide missing support.

The force-stage nonfluid predictor is passed explicitly without mutating accepted cloth state; source finite targets stage exactly once. Cloth-coupled scenes use an explicit integer-time velocity contract: the native startup half-kick is skipped, while every ordinary NB-FLIP particle/grid/advection/force/pressure stage is unchanged. Noncloth scenes retain their native startup kick. Native fluid positions drift before forcing; cloth positions use implicit mechanical drift, so this is a first-order partitioned method requiring timestep-convergence comparisons. All accepted velocity and water-momentum exchanges share the same clock. A temporary staggered-lead experiment was rejected because refreshing its acceleration extrapolation introduced unpaired transient momentum; no phase-correction impulse or tolerance change is used. Strict variable-step freefall (dry and wet), hydrostatic wetting and accepted-momentum/native-impulse gates are provided and remain subject to actual GPU validation.

Local free/bound exchange closes accepted f32 phi with the affine physical-capacity equation, then solves sparse donor/receiver transportation. Transit edges exist only across actual wet shared cell faces inside the sampled local support. Decomposed flow retains original donor velocity for reciprocal momentum; dry textile corridors cannot bridge liquid reservoirs. A deterministic five-cell interface regression exercises transit that direct donor/receiver adjacency cannot satisfy. Actual source capillary validation remains required.
