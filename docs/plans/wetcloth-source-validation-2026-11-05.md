# Released water source implementation status

The 36 imported water fixtures remain validation inputs, not certified paper reproductions. The narrowband FLIP solver remains the liquid owner. Honey/oil/acetal inputs are outside this water-only catalog.

Source import retains shared shell/rod vertices, support masks, groups, SI physical data, all source scripts, CSG, emitters and terminators. The canonical Spot mesh is recovered with author provenance, not asserted byte-identical to the unpublished upstream copy. Source-versus-paper discrepancies remain in the source catalog.

Static source solids use the common sampled procedural surface and its exact local box subtraction for rendering, picking, fluid collision and cloth contact. Cloth's conservative interval query bounds that same trilinear field, including authored cuts.

The towel's six moving clamps have exact rounded-plate SDFs (rectangle plus sphere), not rectangular proxies. Their poses consume the source integrator's right-endpoint cubic updates. Physics shape tag 5 is independent of presentation tags. Native rigid pressure/contact queries and water extraction consume the same body-local oriented box cuts as the shared SVO field program. Native Box3D does not silently substitute an approximate hull for this shape. The new representation remains excluded from general editor placement while its dynamic presentation admission is unfinished.

CPU regressions cover source/shape/SVO distance parity at scripted poses, full 60,000-step clamp trajectory bounds, original surface retention, nearest shared hit testing, cut-through cloth collision, live-pose-local edits, save/load and immutable undo. The full source clamp sweep is contained by the original boundary: min (-0.15616, -0.0005, -0.090000000003), max (0.15616, 0.176625095263, 0.090000000003) metres before the common source offset.

Resident termination walks native GPU resident owners, subtracts exact source box SDFs, updates the compensated native volume budget from actual removed volume, and retires real FLIP records. It does not truncate coverage to the authored scene envelope. Only six boundary bands require fine ownership. BULK16 retirement is not implemented; these source profiles explicitly use native h/4h with `bulkTier: off`. GPU removal/ledger tests passed both quiescent and moving production FLIP fixtures. The moving case began with 6,178 actual live records, retired records inside the terminator, opened native phi, and matched the compensated budget to the removed-volume ledger within 1e-7 cubic metres. A stationary zero-gravity fixture correctly had no live FLIP records and is not used as particle-retirement evidence.

All GPU checks run through the shared GPU runner. Rounded-plate physical SDF/support/volume parity, native apertures and water-extraction cuts/undo, and shared SVO rotated field cuts now pass. A second resident termination stage with the inverted box also passes: it retires every remaining record exactly once (6,177 records in that run). Migrating-world termination, dynamic rigid presentation, and full paper-scene outcome comparisons remain separate gates. Importing, rendering, or passing a geometry unit test is not a reproduction claim.

Solid cohesion surfels retain the source radius h/(2√3), density ceil(area/(πr²)), per-sample sphere volume 4πr³/3, zero water and unit solid fraction. Normals point into the solid, matching the source reversed triangle cross product and inversion sign. The source consumes process-global random area-CDF samples; the new host explicitly uses deterministic area quadrature instead of claiming identical source random samples. Static area integration uses half-cell tetrahedra, with every point projected onto the authoritative trilinear zero surface. Analytic rounded-plate parameterizations and exact oriented-box cut faces retain shared edit geometry. Regressions cover surface residuals, inward normals, area-count convergence, accepted body pose, reactions identity, original samples outside edits, newly exposed faces, save/load and undo.

Only six released water fixtures enable sampled solid surfels: the two buoyancy tests, fuzzy cloth, and the three splash-cloth scales. The towel's six clamps and enclosing solid explicitly use sampled=0, so they do not acquire cohesion surfels merely because the global solid-cohesion switch defaults true. The generic moving and cut sampler remains available and tested for authored sampled bodies.

Source fixtures explicitly select the released application's diagnostic preview palette. The pinned `TwoDSceneRenderer.cpp` uses shell gray (0.75), yarn group grayscale, and blue water blended by each vertex's stored water volume divided by total material control volume, rather than pore saturation. Shell colors interpolate across the physical triangles and yarn colors interpolate between capsule endpoints. This presentation mode is unlit, as in that preview; authored material mode retains the application's existing shaded treatment. The reference preview's wireframe overlay is not reproduced. These are not the paper's Houdini materials; matching offline paper shading and environments remains open. No released XML specifies the optional `haircolor` material field, so no paper fabric color is inferred from a missing property.

The pinned pore-test-mid and towel Houdini archives are readable without executing Houdini. `wetcloth-houdini-appearance-audit-2026-11-06.json` retains hashed archive provenance, camera/render records, selected material parameters and cloth graph connections.
